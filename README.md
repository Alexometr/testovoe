<h1 align = "center">Простое клиент-серверное приложение для скачивания файлов с сервера по сети
<h3>Краткое описание проекта</h3>
  Проект представляет собой клиент-серверное приложение для передачи файлов по сети с использованием TCP-сокетов и многопоточности. В приложении реализована возможность скачивать файлы с сервера, при помощи клиенского приложения, выбирать локальный путь для скачивания файла и локальный путь для загрузки, выбирать chunk определенного размера для скачивания файла, а также выбирать порт сервера
  
# Сборка и запуск
Для сборки проекта необходимо перейти в директорию проекта, вызвать компилятор для C++ для файла .cpp, например:
```
g++ server.cpp
или 
g++ client.cpp
```
Далее, сервер можно запустить при помощи команды
```
./a.out (запустится на порту 8080)

а можно явно указать порт

./a.out -p 9090
```
Для клиента придется явно указать путь к директории, откуда хотим скачать файл и к директории, куда хотим его сохранить. Можно также указать размера chunk`а и порт, но это опционально. Например:
```
./a.out -p 9090 -chunk 128 -dst 127.0.0.1:/home/user/Downloads/file.txt -src /home/user/dir/new_flie.txt

или без дополнительных параметров

./a.out -dst 127.0.0.1:/home/user/Downloads/file.txt -src /home/user/dir/new_flie.txt
```
Готово! Теперь в клиенте вы увидите уведомление о подключении к серверу и прогресс бар скачивания файла в формате <байт получено>/<размер файла в байтах> <скачано % от размера файла>
