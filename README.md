<h1 align = "center">Простое клиент-серверное приложение для скачивания файлов с сервера по сети
<h3>Краткое описание проекта</h3>
  Проект представляет собой клиент-серверное приложение для передачи файлов по сети с использованием TCP-сокетов и многопоточности. В приложении реализована возможность скачивать файлы с сервера, при помощи клиенского приложения, выбирать локальный путь для скачивания файла и локальный путь для загрузки, выбирать сетевой пакет определенного размера для скачивания файла, а также выбирать порт сервера
